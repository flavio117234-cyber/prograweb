5.2 Verdadero o falso

a) La regla @font-face especifica que se utilizará una fuente incrustada cuando el documento se despliegue en una pantalla de computadora.

Falso. La regla correcta es @font-face, no #font-face. Permite utilizar fuentes incrustadas o externas en una página web.

b) Podemos usar gradientes en cualquier propiedad que acepte una imagen.

Verdadero.

c) Un gradiente horizontal cambia en forma gradual de arriba hacia abajo.

Falso. Un gradiente horizontal cambia de izquierda a derecha. Un gradiente vertical cambia de arriba hacia abajo.

d) Podemos agregar líneas entre columnas mediante el uso de la propiedad column-gap.

Falso. La propiedad column-gap establece el espacio entre las columnas. Para agregar una línea entre ellas se utiliza column-rule.

e) La regla @media determina el tipo y tamaño del dispositivo en el que se despliega la página. Cuando el navegador examina la regla, el resultado es verdadero o falso. Los estilos de la regla se aplican sólo si el resultado es falso.

Falso. Los estilos de la regla se aplican cuando el resultado de la condición es verdadero.

f) Para agregar múltiples imágenes de fondo a un elemento, usamos la propiedad background-position para especificar en dónde colocar cada imagen mediante el uso del modelo de cajas.

Falso. Para agregar múltiples imágenes de fondo se utiliza la propiedad background-image. La propiedad background-position sirve para especificar la posición de las imágenes.
