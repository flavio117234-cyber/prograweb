3.2 Indique si cada enunciado es verdadero o falso

a) Cualquier tipo input particular de formulario de HTML5 debe desplegarse de manera idéntica en todos los navegadores compatibles con HTML5.
Falso. La apariencia puede variar dependiendo del navegador.

b) Cuando se coloca el enfoque en el campo de texto, se envía el texto del atributo placeholder al servidor.
Falso. El texto de placeholder no se envía al servidor.

c) No es necesario incluir el atributo autofocus en sus formularios.
Verdadero. El atributo autofocus es opcional.

d) Los nuevos tipos input de HTML5 tienen validación automática del lado del cliente.
Verdadero. HTML5 realiza validaciones automáticas en varios tipos de input.

e) El tipo input range se valida automáticamente cuando el navegador lo despliega como un control deslizante.
Verdadero. El usuario no puede mover normalmente el control fuera de sus límites.

f) HTML5 cuenta con validación automática para el tipo input tel.
Falso. El tipo tel no valida automáticamente el formato del número telefónico.

g) Si el usuario introduce un URL con un formato inapropiado en un tipo input url, no se validará.
Falso. HTML5 valida que tenga un formato de URL válido, pero no comprueba que el sitio exista.

h) El elemento nav muestra un menú desplegable de hipervínculos.
Falso. El elemento nav representa una sección de navegación, pero no crea un menú desplegable.

i) El elemento header puede usarse sólo una vez en una página.
Falso. El elemento header puede utilizarse varias veces.

j) Los elementos nav pueden anidarse en un elemento aside.
Verdadero. Un elemento nav puede colocarse dentro de un aside.

k) Podemos usar el elemento brk para evitar dividir palabras en lugares incorrectos.
Falso. El elemento correcto es wbr.
