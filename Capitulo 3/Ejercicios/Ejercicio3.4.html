Indique si cada uno de los siguientes enunciados es verdadero o falso

a) Los navegadores que despliegan el tipo input color como campo de texto requieren que el usuario introduzca el nombre de un color.
Falso. El usuario puede introducir un valor de color, normalmente mediante un selector de color.

b) Cuando un usuario introduce datos en un formulario y luego lo envía, el navegador verifica de inmediato que los datos sean correctos.
Verdadero. El navegador puede realizar la validación de los datos antes de enviar el formulario.

c) HTML5 puede validar si la dirección de correo electrónico introducida por el usuario existe en realidad.
Falso. HTML5 puede comprobar que tenga un formato válido, pero no puede comprobar si la dirección realmente existe.

d) Puede agregar required a cualquiera de los tipos input.
Falso. El atributo required puede utilizarse en los tipos de input que admiten este atributo.

e) Puede habilitar autocomplete sólo para ciertos elementos input.
Verdadero. El atributo autocomplete puede utilizarse de manera individual en los elementos input.

f) El elemento time nos permite identificar una fecha, hora o ambas.
Verdadero. El elemento time se utiliza para representar fechas, horas o ambas.

g) El elemento caption proporciona una leyenda para la imagen en un elemento figure.
Falso. El elemento figcaption proporciona una leyenda para una imagen o contenido dentro de figure.

h) El elemento details muestra una flecha que apunta a la derecha enseguida de un resumen o leyenda cuando el documento se despliega en un navegador. Al hacer clic en la flecha, ésta apunta hacia abajo y revela el contenido del elemento summary.
Falso. El elemento details muestra el contenido del elemento summary al hacer clic en él.

i) El elemento footer describe el contenido que por lo general aparece en la parte inferior del contenido o del elemento section.
Verdadero. El elemento footer se utiliza para representar el contenido que aparece en la parte inferior de una sección o página.

j) El elemento highlight nos permite resaltar texto.
Falso. El elemento mark es el que permite resaltar texto.
