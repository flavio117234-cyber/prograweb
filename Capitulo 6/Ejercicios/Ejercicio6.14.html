a) x = 7 + 3 * 6 / 2 - 1

Orden de evaluación de operadores:

  1. Multiplicación (*)
  2. División (/)
  3. Suma (+)
  4. Resta (-)
  5. Asignación (=)

b) x = 2 % 2 + 2 * 2 - 2 / 2

Orden de evaluación de operadores:

  1. Residuo/Módulo (%)
  2. Multiplicación (*)
  3. División (/)
  4. Suma (+)
  5. Resta (-)
  6. Asignación (=)

c) x = ( 3 * 9 * ( 3 + ( 9 * 3 / ( 3 ) ) ) )

Orden de evaluación de operadores:

  1. Paréntesis más interno ( 3 )
  2. Multiplicación (*) dentro del paréntesis interno
  3. División (/) dentro del paréntesis interno
  4. Suma (+) dentro del paréntesis intermedio
  5. Primera multiplicación (*) dentro del paréntesis externo
  6. Segunda multiplicación (*) dentro del paréntesis externo
  7. Asignación (=)
