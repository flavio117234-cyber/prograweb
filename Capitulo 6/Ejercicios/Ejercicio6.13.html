Ejercicio: Ecuación en JavaScript

Dada la ecuación y = ax³ + 7, ¿cuáles instrucciones son correctas?

a) y = a * x * x * x + 7;

Correcta

b) y = a * x * x * (x + 7);

Incorrecta

c) y = (a * x) * x * (x + 7);

Incorrecta

d) y = (a * x) * x * x + 7;

Correcta

e) y = a * (x * x * x) + 7;

Correcta

f) y = a * x * (x * x + 7);

Incorrecta

Respuestas correctas: a), d) y e).
