Ejercicio 7.9

Identifique y corrija los errores

a) Código corregido:

if (edad >= 65)
    document.writeln("Edad es mayor o igual que 65");
else
    document.writeln("Edad es menor que 65");

El error estaba en usar el operador incorrecto. Para comprobar si la edad es mayor o igual que 65 se utiliza >=.

b) Código corregido:

var x = 1, total = 0;

while (x <= 10) {
    total += x;
    ++x;
}

El error era que faltaba inicializar total en cero y la condición debe ser x <= 10.

c) Código corregido:

var x = 1;
var total = 0;

while (x <= 100) {
    total += x;
    ++x;
}

El error era que faltaban las llaves para agrupar las instrucciones del ciclo while.

d) Código corregido:

var y = 5;

while (y > 0) {
    document.writeln(y);
    --y;
}

El error era que faltaba cerrar la llave del ciclo while.
