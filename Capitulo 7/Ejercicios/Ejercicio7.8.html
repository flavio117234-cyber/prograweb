Ejercicio 7.8

Instrucción original:

while (z >= 0)
    suma += z;

El problema es que z no cambia dentro del ciclo. Si z comienza siendo mayor o igual que cero, el ciclo puede repetirse indefinidamente.

Una posible corrección es:

while (z >= 0) {
    suma += z;
    z--;
}
