Ejercicio 8.3: Corrección de Errores

a) Error en ciclo while

Error: Había un punto y coma (;) al final de la condición del while, creando un ciclo infinito vacío.

Código corregido:

x = 1;
while ( x <= 10 ) {
   ++x;
}

b) Error en instrucción switch

Error: Faltaba la instrucción break; en el case 1:, provocando que la ejecución cayera al case 2:.

Código corregido:

switch ( n ) {
   case 1:
      document.writeln( "El n&uacute;mero es 1" );
      break;
   case 2:
      document.writeln( "El n&uacute;mero es 2" );
      break;
   default:
      document.writeln( "El n&uacute;mero no es 1 ni 2" );
      break;
}

c) Error en condición de iteración

Error: La condición n < 10 se detiene en 9. Para imprimir hasta el 10 debe ser n <= 10.

Código corregido:

n = 1;
while ( n <= 10 ) {
   document.writeln( n++ );
}
