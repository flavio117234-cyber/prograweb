Ejercicio 8.4: Encuentre el error

a) Error en el ciclo for

Errores:

  • La palabra clave For está escrita con mayúscula inicial (debe ser en minúscula: for).
  • Se usaron comas (,) en lugar de puntos y comas (;) para separar las tres partes del ciclo.
  • Para contar hacia abajo de 100 a 1 se debe decrementar la variable (--x) en lugar de incrementarla (++x), de lo contrario se genera un ciclo infinito.

Código corregido:

for ( var x = 100; x >= 1; --x )
   document.writeln( x );

b) Error en la estructura switch

Error: Faltan las instrucciones break; al final de cada case. Sin el break; en el case 0:, si el valor es par, se imprimirá "Entero par" e inmediatamente después caerá a imprimir "Entero impar".

Código corregido:

switch ( valor % 2 )
{
   case 0:
      document.writeln( "Entero par" );
      break;
   case 1:
      document.writeln( "Entero impar" );
      break;
}

c) Error al imprimir impares decrecientes

Error: Se utiliza x += 2 que incrementa el valor de x en lugar de decrementarlo. Para ir de 19 a 1 debe restarse usando x -= 2.

Código corregido:

for ( var x = 19; x >= 1; x -= 2 )
   document.writeln( x );

d) Error en el ciclo do...while

Errores:

  • La palabra clave While está escrita con mayúscula inicial (debe ser en minúscula: while).
  • La condición contador < 100 detiene el ciclo en 98, excluyendo el número 100. Para incluir el 100 debe ser contador <= 100.

Código corregido:

var contador = 2;
do {
   document.writeln( contador );
   contador += 2;
} while ( contador <= 100 );
